# Catálogo de Superhéroes

Práctica de manipulación del DOM con JavaScript, Bootstrap, HTML y CSS. La aplicación permite visualizar, agregar, eliminar y filtrar personajes.

## Funcionalidades

- Renderizado dinámico de cards al cargar la página desde un arreglo de objeto.
- Formulario para agregar nuevos personajes.
- Filtro por nombre en tiempo real sin recarga de página.
